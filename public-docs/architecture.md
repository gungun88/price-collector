# PriceAI 项目架构

PriceAI 是一个面向 AI 订阅与模型 API 的购买前比价工具。公开页面负责展示价格、渠道、库存、倍数和来源链接；后台负责维护中转 API 站点、报价和提交线索。

## 公开模块

| 模块 | 作用 |
| --- | --- |
| 官方订阅地区价 | 展示 ChatGPT、Claude、Gemini、Grok 等订阅产品的公开地区价格基准 |
| AI 卡网低价订阅 | 整理第三方渠道报价，区分代充、成品号、卡密、CDK 等交付方式 |
| 官方 API / 模型 API | 整理官方 API、模型路由、免费额度、Token Plan 和公开套餐限制 |
| 中转 API 比价 | 比较 API 中转站倍率、充值系数、模型覆盖、可用性和公开披露信息 |

## 自托管后端

当前核心后台采用：

- Next.js 前端
- Fastify 后端
- PostgreSQL 数据库
- Docker Compose 本地/服务器部署

`/admin` 是后台入口。前端通过 `/api/selfhost/admin/*` 代理访问 Fastify 后端，后端读写 PostgreSQL。

## 数据流

```text
公开来源 / 用户提交 / 管理员录入
  -> 自托管 Fastify API
  -> PostgreSQL
  -> Next.js 前台列表、详情页和后台管理页
```

## 边界

- PriceAI 不卖货、不收款、不承诺渠道售后。
- 公开页面展示来源、原始标题、价格、库存、倍数、更新时间和链接，方便用户回原站核验。
- 官方价格、第三方渠道价、官方 API 和中转 API 不混成同一类风险。
- 缺货、过期或未审核信息不能作为外层最低价或客观榜单依据。
